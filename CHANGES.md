## How this fork is distributed

This engine is consumed as the `necpp_src` submodule of
[`stevenmburns/python-necpp`](https://github.com/stevenmburns/python-necpp),
whose GitHub Releases publish prebuilt PyNEC wheels. The complete corresponding
source for those wheels is this repository — at the commit pinned by the
matching `python-necpp` release — together with `python-necpp` itself. This
repository is public, and the relevant commits are kept available for as long as
the corresponding wheels are distributed.

## Modifications (2026)

Relative to `tmolteno/necpp`:

- **OpenMP-parallelised matrix fill.** `src/nec_context.cpp` and
  `src/nec_context.h` parallelise the NEC2 interaction-matrix fill with OpenMP.
- **LAPACK/LAPACKE solve path.** `src/matrix_algebra.cpp` routes the dense LU
  solve through LAPACKE (`zgetrf` / `zgetrs`), so the engine can link a tuned
  BLAS (OpenBLAS or MKL) instead of the hand-rolled solver.
- **MSVC / portability fixes.** Thread-local handling in `src/c_ggrid.cpp` (the
  GCC-only `__attribute__((tls_model(...)))`) made portable for the MSVC build.
- **Build configuration.** `configure.ac` and `src/Makefile.am` updated (e.g.
  OpenMP flags); the generated `config/m4/libtool.m4` removed from version
  control and gitignored (it is regenerated by libtoolize at build time).
